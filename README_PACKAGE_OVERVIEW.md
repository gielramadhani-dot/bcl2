# Macaflavone–BCL-2 Supplementary GitHub Package

Prepared for upload to GitHub as a supplementary/reproducibility package for the manuscript on integrated docking, pilot molecular dynamics, and ligand-based GNN prioritization of Macaflavone candidates targeting the BCL-2 canonical groove.

Prepared: 2026-06-15T11:46:17Z

## Recommended repository name
`macaflavone-bcl2-integrated-docking-md-gnn`

## Package content

- `01_Manuscript_and_SI_documents/`: current manuscript drafts and article document.
- `02_Main_figures_final/`: final main figures named consistently as Figure 1–7c.
- `03_Main_tables_csv/`: manuscript Tables 3–8 in CSV format.
- `04_Drive_Stage9C_GNN_final_package/`: final GNN interpretation, claim boundary, and summary files downloaded from Drive.
- `05_Drive_Stage9D_molecular_GNN_visualization/`: molecular GNN visualization and atom-saliency files downloaded from Drive.
- `06_Drive_Stage9E_docking_GNN_validation_CHECK_BEFORE_USE/`: docking–GNN validation files downloaded from Drive. **Check Table 33 before using it as a main result because it may contain Macaflavone I/Macaflavone II mapping duplication.**
- `07_Article_source_assets/`: alternative exact-analysis figures generated from numerical data.
- `08_Reproducibility_notes/`: availability statements, software notes, and minimal environment files.
- `09_Missing_items_to_add_before_final_GitHub_release/`: checklist of raw/script/model/trajectory files that were not found in the currently downloaded package.

## Important interpretation boundary

The repository supports computational prioritization only. Docking, pilot MD, and ligand-based GNN outputs do not confirm BCL-2 inhibition, apoptosis activation, or functional biological activity.
