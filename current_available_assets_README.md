# Macaflavone BCL-2 current available assets

This archive contains the currently available manuscript assets for the BCL-2 Macaflavone docking-pilot MD-ligand-based GNN article.

## Folders
- `manuscript/`: DOCX manuscript drafts generated in the current workspace.
- `figures/`: Figure 1-Figure 7 PNG files.
- `tables/`: manuscript summary tables in CSV format.
- `metadata/`: availability manifest and missing-data notes.

## Scope warning
This is not yet the complete GitHub reproducibility repository. Full raw BCL-2 docking, pilot MD, and GNN scripts/model files still need to be added if they exist in another Drive folder or Colab output directory.
