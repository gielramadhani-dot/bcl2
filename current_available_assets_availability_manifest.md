# Availability manifest for current BCL-2 Macaflavone package

This package contains the assets currently available in the active workspace for the manuscript: integrated docking, pilot molecular dynamics, and ligand-based GNN prioritization of Macaflavone candidates targeting BCL-2.

Included:
- Current manuscript DOCX drafts.
- Final/current figure PNG files for Figures 1-7.
- CSV versions of Tables 3-8 reconstructed from the manuscript data used in the current conversation.

Not confirmed as present in Google Drive:
- BCL-2 raw receptor/prepared receptor files.
- Venetoclax/Macaflavone docking PDBQT/PDB pose files.
- BCL-2 pilot MD trajectory, topology, and MDP files.
- Original BCL-2 ChEMBL4860 raw/cleaned dataset files.
- Original GIN-GNN training scripts, model weights, baseline RF/Ridge models, and atom-saliency scripts for the BCL-2 version.

Important: these CSV tables are manuscript-ready summary tables, not full raw computation outputs.
